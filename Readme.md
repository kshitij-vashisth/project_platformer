
# Game Project Overview: Retro-Inspired 2D Action Platformer

This project is a **retro-inspired 2D action platformer** built from scratch using **Godot Engine**. The game combines **fast-paced gameplay**, **tight controls**, and **modern mechanics** with a **gritty, nostalgic edge**.

Currently, the game features **basic mechanics** and **limited levels**, but they work much smoother, emphasizing **precise movement** and **fluid traversal**. This remake aims to expand upon the original experience and provide a **dynamic, evolving platforming journey** with new mechanics, levels, and narrative content over time.

## Key Features

- **Tight Controls & Precision Movement**: Designed for players who appreciate responsive and fluid gameplay, featuring:
  - **Wall Jumps**
  - **Dashes**
  - **Grappling Hook**
  
- **Combat System**: Reticle-based aiming for responsive and intuitive combat mechanics.

- **State Machine**: Integrated into the code to enable easier debugging, prevent spaghetti code, and add new features seamlessly. This structure sets the stage for expanding mechanics and features down the line.

- **Challenging Gameplay**: Expect traps, enemies, and environmental hazards that demand quick reflexes and adaptability.

- **Pixelated Chaos**: Handcrafted levels with reactive traps, AI enemies, and score-based objectives to keep the gameplay engaging and challenging.

- **Controller & Keyboard Support**: Optimized for both **keyboard/mouse** and **controller** inputs, ensuring a smooth experience no matter your preferred method of play.

- **Future-Proof Design**: The game is structured for future content updates, such as additional mechanics, levels, and narrative expansion, ensuring an evolving platforming experience.

## Current Status

- **Levels**: The game currently has **no levels**, but the framework for level design is set up for future expansion.
- **Mechanics**: While the mechanics are **limited**, they are working **much smoother**, with solid movement and combat already in place.
- **State Machine**: The inclusion of a state machine greatly simplifies adding features and debugging, allowing for easy expansions as the project progresses.

## Upcoming Features

- **Levels and Progression**: Adding levels, challenges, and a structured progression system.
- **Expanded Mechanics**: Including more movement mechanics, traps, enemies, and interactive environments.
- **Narrative & Cinematics**: A more fleshed-out story with cinematic cutscenes to follow the chaotic journey.
- **More Customization**: Further improvements on the player character and environmental interactivity.
